3일차_프로젝트_뜯어보기.md

1. 각 디렉터리의 역할
   app/core/ : 환경 변수, DB 연결 등 프로젝트 전반에서 사용하는 공통 설정 관리
   app/models/ : SQLAlchemy를 사용하여 데이터베이스 테이블 구조를 파이썬 클래스로 정의
   app/repositories/ : 데이터베이스 조회, 생성, 수정, 삭제 등 CRUD 작업을 담당
   app/schemas/ : Pydantic을 사용하여 API 요청과 응답 데이터의 형식 및 유효성을 검증
   app/services/ : 이메일 중복 확인, 회원가입 등 실제 비즈니스 로직을 처리
   app/apis/ : API URL, HTTP 메서드, Request Body, Response를 정의하고 Service와 연결

2. 주요 파일의 역할
   app/main.py : FastAPI 애플리케이션을 생성하고, 작성한 API Router를 등록하는 파일
   app/core/config.py : .env 파일에 작성한 환경 변수를 읽는 파일
   pyproject.toml : 프로젝트 정보와 필요한 라이브러리를 정의하는 파일
   uv.lock : uv.lock은 설치되는 라이브러리의 정확한 버전을 기록하는 파일

3. 데이터 베이스 연결 설정
   app/core/db/databases.py : 데이터베이스 연결을 생성하고, API 요청마다 사용할 DB Session을 제공

4. SQLAlchemy를 활용하여 모델을 작성하고 alembic을 활용하여 마이그레이션을 수행하는 방법
   
   SQLAlchemy는 파이썬 클래스를 데이터베이스 테이블과 연결하는 ORM 도구
   Alembic은 모델 변경 사항을 데이터베이스에 적용하는 마이그레이션 도구

        User 클래스
        ↓
        users 테이블
        ↓
        회원 데이터 저장

마이그레이션 순서
1. app/models/user.py에 모델을 작성한다.
2. Alembic이 모델 정보를 읽도록 alembic/env.py를 설정한다.
3. 마이그레이션 파일을 생성한다.
4. 데이터베이스에 변경 사항을 적용한다.

5. API 구현 흐름
   클라이언트가 POST /users 요청
        ↓
   app/apis/user_apis.py
        ↓
   UserCreateRequest로 입력값 검증
        ↓
   app/services/user_service.py
        ↓
   이메일 중복 검사 및 회원가입 로직 수행
        ↓
   app/repositories/user_repository.py
        ↓
   app/models/user.py를 사용하여 DB에 저장
        ↓
   UserResponse 형식으로 응답 반환
